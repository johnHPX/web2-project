
# Claquete API

> Uma API temática de cinema e séries, desenvolvida com foco em gerenciamento de catálogos, controle de acesso por dias da semana, sistema de logs de requisições e exportação de relatórios em PDF.

Trabalho acadêmico desenvolvido para a disciplina/atividade prática em equipe.

---

## Tecnologias Utilizadas

*   **Node.js** & **Express.js**
*   **JavaScript**
*   **PDFKit**
*   **Vercel**
*   **Git & GitHub**

---

## Requisitos Atendidos do Projeto

- [ ] **A.** Rota `GET` para obter a lista completa de itens (filmes/séries).
- [ ] **B.** Rota `POST` para inserir um novo item no array mockado.
- [ ] **C.** Rota `DELETE` para excluir um item pelo identificador.
- [ ] **D.** Rota `GET` para pesquisar um item pelo código.
- [ ] **E.** **Middleware de Dias Úteis:** Permite o acesso à API apenas de segunda a sexta-feira.
- [ ] **F.** **Middleware de Logs:** Registra o horário, a rota e o método de cada requisição realizada.
- [ ] **G.** Rota `GET` para consultar/retornar os registros de requisições de uma data específica.
- [ ] **H.** Rota `GET` para gerar e baixar um relatório em formato **PDF** com a lista de itens.
- [ ] **I.** **Dados Mockados:** Todos os dados iniciais vêm estruturados em memória.
- [ ] **J.** **Versionamento:** Código versionado seguindo o fluxo de branches no GitHub (`claquete`).
- [ ] **L.** **Deploy em Nuvem:** Aplicação publicada e acessível via Vercel.
